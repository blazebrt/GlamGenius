# GlamGenius Review Policy

This policy governs pull requests and changes to `main` for the GlamGenius V2 production architecture.

## 1. Principles

1. **Owner self-review is permitted.** The repository owner may review and merge their own pull requests.
2. **Owner self-merge is permitted.** A pull request may be merged by its author once all required automated checks are green.
3. **Independent review is encouraged but not required.** While a second set of eyes is always valuable, it is not a mandatory block for merging.
4. **Required approving review count is zero.** Branch protection does not mandate a minimum number of human approvals.
5. **AI-authored work must be disclosed.** Any code generated by an AI assistant must be clearly stated in the pull request description and commit messages.
6. **Automated tests and truthful evidence remain mandatory.** No PR may bypass the CI pipeline. The author must provide real, accurate evidence of testing.
7. **Every merge is squash-merged.** `main` history is linear.
8. **Direct commits to `main` are blocked.** All changes must go through a pull request to ensure CI runs.

## 2. What the Author Checks

Before merging, the author (or reviewer, if present) must ensure:

1. **Scope** — The PR does what the description says and only that.
2. **Tests** — The PR fills the "Tests actually run" section with truthful output.
3. **Secrets** — No secret material is committed. The CI secret-scan job is a safety net, not a substitute.
4. **CI signal** — Every required check on the head commit is green.
5. **AI Disclosure** — If AI assisted in writing the code, it is noted.

## 3. AI-authored changes

1. AI-authored commits should be marked in the commit message trailer: `AI-assisted-by: <tool name>`.
2. The PR description must state which parts of the diff were AI-generated.
3. The human author remains fully responsible for the correctness, safety, and security of the AI-generated code.

## 4. Change control

This document lives in `docs/engineering/REVIEW_POLICY.md`. Amendments require a pull request and passing CI.
