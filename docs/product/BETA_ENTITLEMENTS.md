# Beta access

GlamGenius is currently invite-only. Subscriptions, upgrades, and
commercial-access controls are not active in beta.

| Capability | Invited beta account |
| --- | --- |
| Style, Care, and planning | Available |
| Product verdicts and shared shelf | Available |
| Personal modes | Available |
| Family Circle | Available |
| History and daily manager | Available |

Operational usage limits protect service reliability; they are not a paid
plan, an upsell, or a reason to remove a listed feature from an invited person.
