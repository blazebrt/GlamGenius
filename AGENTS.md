# GlamGenius product boundary

GlamGenius pivoted. Do not infer scope from old code, old migrations, or git
history. `PRODUCT_CONSTITUTION.md` is product authority.

Current product: an India-first decision engine for things entering or touching
the human body. Primary habit: before buying or using a product, check
GlamGenius. Current loop: **SCAN → UNDERSTAND → DECIDE → REMEMBER → MANAGE**.

Permanently rejected: wardrobe product, Style Me, style quiz, colour analysis,
virtual try-on, general outfit generation, salon directory, unrestricted AI
chat, and public social. Legacy code that contradicts this is deletion debt,
not permission.

Do not implement a new customer feature until you map it to the Constitution.
If instructions conflict, the Constitution wins and the agent must stop.
